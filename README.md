# 省吃

面向临时决定吃麦当劳的食客。它根据当前位置或城市关键词选择门店，读取当前菜单，校验这家店真正可用的优惠券，并用官方接口核价。热量只在营养库精确命中时展示。

本项目是麦当劳程序员创意开发大赛参赛作品，不是麦当劳官方产品。输出仅供参考，不构成营养或医疗建议。价格、库存和券可用性以官方实时结果为准。

## 目标用户

- 现在想吃，但还没决定店、套餐和预算的食客。
- 需要确认优惠券在当前门店是否真的可用的食客。
- 需要在下单前核对官方价格和可选热量的食客。

## 安装

1. 在 [麦当劳 MCP 开放平台](https://open.mcd.cn/mcp) 用手机号登录并申请 MCP Token。
2. 在 WorkBuddy 的自定义连接器中配置 `mcp-config.example.json`，把 `${MCD_MCP_TOKEN}` 替换为本地环境变量。不要把真实 Token 写入仓库。
3. 信任并启用 `mcd-mcp` 后新建对话。
4. 将本仓库作为 Skill 使用，或把 `SKILL.md` 放入 WorkBuddy Skill 目录。

## 使用示例

在已启用麦当劳 MCP 的对话中说：

```text
我现在在上海人民广场，预算 30 元，想吃辣的，先不要下单。
```

Skill 会查询附近到店门店和当前菜单，筛出预算内候选，检查门店可用券，并对选中候选调用官方核价。它不会自动领券、创建订单或支付。

本地确定性脚本不访问网络：

```bash
python3 scripts/now_decision.py channel --name pickup
python3 -m unittest scripts/test_now_decision.py
```

## 边界

- 不自动下单、取消订单、领券、兑换、抽奖或新增地址。
- 账户里有券，不等于当前门店可用。
- 活动文案中的价格不是订单价。
- 套餐不能直接使用同名单品的热量。
